# 🎡 Rotating Wheel (HTML + CSS)

This project demonstrates a colorful, animated rotating wheel built using only HTML and CSS. The wheel rotates when hovered over and reverts to its original position when the mouse is moved away.

---

## 🔗 Live Demo

- 🌐 GitHub Pages: https://manjot-singh-mattu.github.io/rotating-wheel/

---

## ✨ Features

- 🎨 Conic-gradient colored segments
- 🌀 Rotates smoothly on hover using CSS animations
- 🕳️ Hollow (donut-style) center
- 💡 Simple and responsive design
